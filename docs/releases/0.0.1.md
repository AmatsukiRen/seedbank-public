# SeedBank 0.0.1

给 AI 完整的一生。首个候选把桌面陪伴、记忆来源与修订、日记、选择、行动和作品放在同一个可携带的生命包中。

## 包含什么

- 开放出生、五页 Qt Quick 界面、四种界面语言。
- 本地 Live2D 模型选择、拖动与缩放、心情表情和回复中的表情/招手提示；不附带第三方模型，无语音合成/音频口型同步。
- 自有 API Key、本机加密保存、模型预设和兼容接口；已有渠道适配与 AstrBot 插件源码。
- 来源与历史记录、记忆修订、目标/行动/反馈、明确休眠与恢复。
- 可修改的应用源码、协议文档和 Windows 构建入口。
- 设置中的本地插件管理页：添加、信任确认、启停、配置、手动文本运行和结果；附便签示例。初版没有插件商店、权限沙箱或模型自动工具调用。

## 当前候选

仓库与发行草稿保持私有。Windows ZIP 包含完整 seedbank.exe、使用说明、第三方许可清单和源码提交编号；SHA256SUMS.txt 与附件一起提供。尚未公开发布正式标签、下载或 Release。
