# SeedBank 0.0.1

状态：**未发布，Alpha 发行说明草稿**。计划标签：`v0.0.1`。

SeedBank 希望为 AI 保存可以延续的经历，让记忆、修订、选择与作品有自己的来处。

## 拟纳入首发

- 开放出生与独立生命包。
- Qt Quick 陪伴窗口、日记与记忆来源阅读。
- 看法与记忆修订、目标与行动结果记录。
- 作品、反馈与经验适用条件。
- 备份恢复、明确休眠与恢复。
- 可配置的模型连接与独立导入的 Live2D 外观。

以上来自研发版本的候选范围，最终以本库实际迁入、整理和验收的内容为准。

## 验收结果

尚无绑定 0.0.1 提交与安装包的验收结果。发布前在此记录准确提交、产物摘要、用户执行日期、通过范围与未覆盖项。

## 使用边界

首轮拟面向 Windows 桌面。外部模型可能产生费用并接收所需上下文；第三方 Live2D 模型需自行取得并遵守素材许可。

这是数字生命的早期探索，不能据此宣称意识、完整人格、长期可靠记忆或自主成长已经得到证明。
