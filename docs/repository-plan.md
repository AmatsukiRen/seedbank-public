# 产品仓库与源码迁入

本库就是将来公开的 SeedBank 产品仓库。当前以私有状态准备，完成后公开同一仓库，不再额外维护独立介绍网站或长期的设计稿仓库。

原研发库保存历史实现和阶段记录。应用迁入后，产品库成为后续开发的主入口，原库作为档案，避免长期双向维护。

## 现有内容

三语 README、完整故事、认可的品牌头像、素材署名、接口指南、贡献说明和离线参考客户端。旧版三张同页截图只保留来源历史，不用于当前首页展示。独立 HTML 站点已移除。

## 迁入清单

| 内容 | 整理要求 |
| --- | --- |
| Python 核心、CLI、Qt Quick | 使用当前实现和必要资源，逐文件迁入 |
| 种子与旧档案兼容 | 默认开放出生，保留必要读取与打包依赖 |
| 离线测试与人工样例 | 保留可公开的人工材料，用户执行验收 |
| 打包与固定启动器 | 统一版本、图标与通用路径 |
| 使用与协议文档 | 说明首次使用、数据来源、模型费用、备份恢复及扩展 |
| 适配器与示例 | 明确依赖、状态和支持范围 |

不复制原仓库的 .git、真实生命包、密钥、连接配置、原始日志或第三方模型本体。迁移中产生的新修复逐项登记，在切换前同步。

公开与首次 Release 仍需明确发布指令；内部交付记录在原研发库维护。
