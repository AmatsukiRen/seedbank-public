## 静态审阅中处理的问题

1. 旧包元信息 1.2.0 与运行核心 1.23.0 不一致：统一应用版本为 0.0.1，并让安装元信息、CLI、Qt 窗口和 Windows 文件版本读取同一来源。生命包和协议格式版本不变。
2. 默认 Live2D 指向维护者 D 盘：改为空选择，有明确提示和入口；已有用户显式选择的模型路径仍保留，清除选择不删除模型文件。
3. Python 包遗漏语言资源、README 不存在：补齐资源配置和说明。依赖要求按 Live2D 运行库调整为 Python 3.11+。
4. 原文档仍要求回到研发库找源码：更新三语首页、安装、扩展和贡献指南。

## 交付与边界

本库最初为 PRIVATE，2026-11-04 维护者明确决定公开并发布 v0.0.1 预览版。Windows 程序只放在 Release 附件，不写入 Git 历史；演示公皮不在 Git 或发行包中。最初迁入时未运行测试，之后验收与打包对应关系见 [acceptance.md](acceptance.md)。

用户已完成当前 exe 的专项验收，决定保留 Live2D 并不发送询问。外部许可条件和未确认范围仍如实记载，不以维护者决定代替第三方授权；见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 源码公开与 Windows 发行分别推进

Live2D 功能继续保留。自有集成代码的公开准备与包含 SDK 的程序发行分别记录，不能把存在 Live2D 接口理解为禁止公开自身源码，也不能把源码 MIT 理解为给 Core、角色和截图重新授权。

| 交付 | 实际包含 | 当前仍须处理 |
| --- | --- | --- |
| Git 仓库 / 应用源码 ZIP | 自有 Python/QML、协议、插件示例、构建方法、文字种子、已有头像与截图；不附 Qt/Cubism 二进制 | 保留 MIT、种子 CC BY-SA、角色 CC BY-NC-SA 及来源说明 |
| Windows ZIP | 已验收 exe、运行库、更新文档和许可证；没有公皮资源 | SDK 尚无项目专属许可答复；维护者决定发布并保留说明 |
| 第三方源码 | 官方 Qt/PySide 6.12.0 完整源包和原始通知 | Release 独立附件；修改库重建尚未实测，不作全部合规认证 |

仓库及历史含有品牌衍生头像和演示截图，按维护者决定保留；不称为“没有第三方形象”。未分发的是模型本体、纹理、动作和 PSD。没有重写历史。

生产入口为每个 exe 记录 `runtime-build.json`，候选入口产生同提交 Source ZIP。公开时的文档组包单独使用 `assemble_release.py`，保留原运行程序及源码 ZIP，另记文档提交和源码附件；因此发行标签可能比运行源码提交更新，但不把后续应用改动冒充已编入旧 exe。详见[开发说明](development.md)。
