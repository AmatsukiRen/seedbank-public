# 指定群旁听与学习

本页描述尚未发布的本地候选。已发布的 0.0.2 不包含此功能；当前完整修订尚待用户执行测试。

旁听让个体把群里实际听到的话留成见闻，在以后需要时回想。它使用同一份生命档案，不建立一个独立的“群聊人格”。这里的学习是保存来源、提炼笔记、以后检索和运用，不修改模型权重，也不保证群里的说法正确或个体已经掌握某项能力。

## 如何开启

1. 在 **设置 → QQ / 聊天渠道 → 旁听与学习** 填写群或频道 ID，多个用逗号分隔。空白表示关闭，默认关闭，最多 20 个群。
2. 设置每日整理调用上限，默认 4 次，可填 1–20。多个运行中的旁听连接共享同一个体的日计数，并采用其中最小的上限。
3. 保存设置，重新启动该连接。程序重开不会自动连接；新建个体不会继承另一个体的 QQ 旁听选择。
4. 在 **查看旁听记录** 中查看待整理原文、处理状态和笔记。可主动整理一批，也可放下待整理内容或历史批次。

旁听名单与回复白名单独立。例如，只旁听群 A、仅在群 B 被 @ 时回答，可将 A 填入旁听名单、B 填入回复白名单。同一个群在两个名单中时，明确 @ 优先走原有对话回复；普通文字走旁听，不重复收录为两次经历。只有旁听权限的群即便 @ 也不会触发回复。

## 接收范围

| 接入 | 本轮代码范围 |
| --- | --- |
| QQ / OneBot，包括已有 SnowLuma、NapCat、LLOneBot 路径 | 桌面当前个体的已配置群文字上报；去重、忽略自己发送的消息，不下载图片或其他附件 |
| Telegram、Discord、飞书、钉钉直连 | 共享入口接受符合身份校验、来自指定群的实际推送文字；未做真实平台验收 |
| AstrBot | 仍为显式 `/seed` 转交，本轮不开放旁听 |
| 独立 `seed qq` 命令行 | 未接入本轮的桌面旁听调度 |

**平台没有推送的消息，SeedBank 就无法旁听。** 此功能不获取历史、不绕过机器人权限，也没有为飞书、钉钉另加全群消息读取权限或历史接口。平台只推送 @ 时，配置旁听名单不会使其自动变成全群消息订阅。连接和权限配置参见[渠道说明](channels.md)。

## 如何整理与记住

- 每条接纳的文字先记入 `mind/experiences.jsonl`，带渠道、账号、群、发言者、平台消息 ID、接收时间和可见范围，并标为他人说法。之后可在允许的范围内检索；不必等模型摘要成功才留下原文。
- 桌面每分钟的活动检查最多处理一批。同一渠道、账号和群的消息才会组成一批；满 20 条或最早消息等待 5 分钟后可以整理。每批实际提交正文不超过 6,000 字。
- 模型只收到本批原文，不附带主人私人日记、其他群内容，也没有发消息或执行工具的通路。模型最多提炼 3 条、每条 180 字，必须引用输入来源。无值得记录的内容可以不产生笔记；离线模板也不会伪造学习结果。
- 笔记进入普通记忆，带“他人说法／尚未核实”标记及来源依赖。主人可以回顾；群里只能检索该群允许的内容。默认不跨群传播，不直接改写出生身份、目标或人格。
- 来源、笔记和额度状态随生命包备份。普通聊天的自身状态会获知是否启用了旁听及本次连接已收录数量，不会把“已经启动连接”说成“已学会群里的知识”。

调用上限是**请求次数**，不是 token 或费用上限。使用当前模型可能收费；并非每条消息都发起请求，也没有因摘要不理想而追加请求。每批尝试在调用前落盘，失败、无效来源或中断不自动重试；重开程序不会清零。正常跨日重置，时钟向后调不会续额。

最多暂存 80 条待整理消息，每天接纳最多 1,000 条，超额不保存。待整理超过 24 小时的原文仍可回顾，但不再自动提交给模型。休眠、停止连接或从旁听名单移除群时，不再为其启动整理；已经开始的请求需等待结束，不能撤回已提交的输入。

## 放下与审阅

记录每页显示 10 批，可翻阅更早批次。放下待整理内容不会调用模型；放下历史批次后，原文和依赖它生成的笔记退出后续检索，相关派生记录沿现有遗忘依赖规则处理。**这是停止回想，不是物理擦除**：原文、笔记与操作痕迹保留供本人审阅，无法收回此前已经发给模型的内容。

关闭旁听停止后续收集和整理，不会自动遗忘已保存的见闻。如希望这批内容不再被回想，需要另外“放下”。

## 由用户运行的验收

源码入口：`packaging/run_observation_checks.ps1`。准备了 22 项旁听逻辑用例和 2 项 Qt Quick 用例，使用临时生命包、假模型与假发送器，阻止网络连接，不打开真实账号或原生 Live2D。执行后日志保存在仓库 `artifacts/observation-*.log`；本机独立交付入口可另指定日志目录。

完整关联回归可运行 `packaging/run_offline.ps1 -Suite integrations`、`-Suite core`、`-Suite security`。生产 exe 的独立验收入口仍为 `packaging/run_candidate_checks.ps1`。这些入口交由用户执行，不以生产打包成功代替验收。

手动界面步骤：使用独立测试生命包，先保持模型离线，查看 QQ 与聊天渠道两处设置、四语及弹窗关闭；确认保存与重开、默认关闭、记录翻页。真实群收发另行由用户在自己指定的测试群确认：普通发言只旁听、@ 回复只遵守回复名单、非指定群不收录，撤回后不再召回。真实模型及平台本轮未验收。
