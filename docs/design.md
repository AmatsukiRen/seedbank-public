# SeedBank 对外页面设计

本库是对外设计稿的维护入口。首发目标为 0.0.1，当前保持私有，页面尚未部署。

## 页面与文件

- `site/index.html`：介绍页。下载仓库后双击即可查看。
- `site/style.css`：版式、颜色与响应式布局。
- `site/story.js`：四段人工示例的切换，支持键盘操作。
- `assets/brand/seedbank-logo.png`：已认可的品牌头像。
- 根目录 `README.md`：GitHub 首页文案与排版草稿。

## 视觉方向

面向对 AI 陪伴和数字生命感兴趣的使用者，以白底、蓝色、女仆品牌头像和清楚的文字层级组织内容。角色建立第一印象，经历与选择是页面主线。

首屏文案：**一起经历，慢慢成为自己。**

| 元素 | 设计 |
| --- | --- |
| 背景与正文 | 白底，主文字 `#1C2945`，次级文字 `#53617A` |
| 强调色 | `#3558B4`，浅蓝区域 `#F1F5FC` |
| 控件与阅读区 | 按钮圆角 12px，阅读区圆角 24px，头像保留原圆角 |
| 字体 | 系统中文无衬线字体，不远程加载 |
| 动态 | 仅按钮交互反馈，尊重减少动态效果设置 |
| 页面主题 | 固定浅色，保持白底品牌方向 |

采用原生 HTML、CSS 与 JavaScript，无需构建；不加载外部图片、字体、统计服务或模型接口。

## 内容顺序

介绍页：第一次见面 → 开放出生 → 相遇、记住、改变、继续 → 日常场景 → 首次使用 → 常见问题。

GitHub 首页：品牌与一句话介绍 → 项目核心 → 实际界面 → 使用入口 → 数据与模型服务 → 当前进展 → 贡献与许可。内部逐轮记录不作为公开首页的主要内容。

书店示例是人工编写的机制说明。它不来自真实个体，不表示模型已通过相关场景验收。关闭 JavaScript 后按顺序显示全部示例。

## 参考与取舍

- [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)：借鉴统一的 README 视觉、清楚的导航和真实界面展示。
- [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)：借鉴实际效果、安装入口和扩展文档的组织方式。

没有复制这两个项目的代码、横幅、角色图或动画。SeedBank 页面围绕记忆与人生记录组织，应用仍保持陪伴、日记、记忆、生活、设置五个入口。
