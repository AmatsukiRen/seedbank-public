# 编写第一个 SeedBank 插件

[首页](../README.md) · [扩展接口](extensions.md) · [完整便签示例](../examples/plugins/hello/)

0.0.1 新增 **设置 → 插件与扩展**。初版是手动文本工具：添加本地插件、查看作者和版本、配置、确认信任、启用或停用、运行、停止、查看结果和从列表移除。它不是插件商店，也不是让模型自动调用任意代码的工具代理。

## 使用流程

1. 点击“添加便签示例”，或从可信作者取得一个文件夹，点击“添加本地插件”并选择其中的 `plugin.json`。
2. 导入只读取和复制文件，新插件默认停用。查看作者、版本、说明、访问声明及代码后，再点击“启用插件”确认信任。
3. 填写配置和本次输入，点击“运行插件”。运行时采用当前填写的配置，并保存到本机。结果可以选择复制；不会自动写入记忆或送给模型。
4. 点击“停止运行”可取消当前任务。单次运行上限为 30 秒；关闭程序也会请求停止。休眠期间不接受运行请求。
5. “从列表移除”取消登记和启用状态，**保留文件**。需要删除文件时，可在移除前打开插件文件夹自行处理。重新添加同 ID 会导入新副本并恢复为停用状态，配置按新清单默认值重新设置。

插件登记和受管理副本位于当前用户的 `~/.seedbank/plugins/`，不属于某一个生命包，也不随生命包备份。重开保留配置和启用状态，但不会自动运行插件；本次输出只在窗口中保留。

## 一个最小插件

文件夹中放置 `plugin.json` 和 `main.py`。不需要安装独立 Python 才能在 Windows 候选中运行此示例。

```json
{
  "id": "example.notes",
  "name": "文本便签",
  "version": "0.0.1",
  "author": "你的名字",
  "description": "把手动输入的文字整理为便签。",
  "protocol": "seedbank/plugin@1",
  "entry": "main.py",
  "access": [],
  "settings": [
    {"key": "prefix", "label": "便签标题", "default": "今天的小事"}
  ]
}
```

```python
def handle(request):
    title = request["settings"].get("prefix", "今天的小事")
    lines = [line.strip() for line in request["input"].splitlines() if line.strip()]
    return {"text": title + "\n" + "\n".join("• " + line for line in lines)}
```

宿主向 `handle(request)` 传入：

```json
{"protocol":"seedbank/plugin@1","input":"本次手动输入","settings":{"prefix":"今天的小事"}}
```

函数返回 `{"text":"结果"}`。工作进程负责包装协议；插件不必直接读写标准输入输出。普通 `print` 不会混入返回协议，当前也不展示完整 stderr 或堆栈。开发时请在独立人工环境调试；插件异常在界面报告运行失败。

## 范围与约束

| 项目 | 当前约定 |
| --- | --- |
| 协议 | `seedbank/plugin@1`，初版实验接口；变更将记录在文档中，尚非长期稳定 SDK |
| 入口 | 文件夹内的 `.py` 文件；不接受目录外入口、符号链接或联接目录 |
| 大小 | 最多 256 文件、8 MiB；导入跳过 `.git`、`__pycache__` 和 `.pyc/.pyo` |
| ID / 配置键 | 小写字母开头，共 3–80 字符；后续允许数字、点、横线、下划线 |
| 配置 | 最多 12 个字符串字段，每项最多 1,000 字；**明文保存，不存秘密** |
| 输入 | 最多 4,000 字；含配置的序列化请求最多 20,000 字节 |
| 输出 | 最多 12,000 字；协议输出最多 64 KiB；始终按纯文本显示 |
| 调度 | 一次一个，手动触发，最多 30 秒；不支持后台常驻、定时任务或自动重试 |
| 依赖 | 示例仅使用标准库；当前无 pip 安装器，不承诺任意第三方 Python 包可用 |
| 变更 | 受管理文件与导入指纹不同则拒绝启用/运行；更新需重新添加并确认信任 |

`access` 可列 `network`、`files`，作为作者告知使用者的声明。它**不是操作系统权限控制**。独立进程仍以当前系统用户权限运行，能自行读写文件或联网。宿主不会在请求中自动附带生命包、聊天历史、模型连接或凭据，也不继承模型/机器人密钥环境变量；这些措施不能阻止恶意插件自行读取本机资料。不要把它称为沙箱。

停止操作会终止工作进程；Windows 同时尝试终止其子进程树，其他平台使用独立进程组。插件不得创建脱离该进程树的后台服务；这不是对恶意进程的隔离保证。无需访问文件或网络的插件应声明 `access: []` 并遵守该声明。

## 与模型、渠道和生命经历的关系

现有模型适配器、QQ/OneBot、Discord、Telegram、飞书、钉钉和 AstrBot 转接有各自的设置入口。插件页提供导航，**不会**把这些已经独立运行的连接误装成文本插件。新增聊天平台请先阅读 [渠道文档](channels.md) 和 [载体桥](extensions.md)。

未来如果让个体自主使用工具，仍需增加明确的能力授权、输入范围、目标关联、行动回执和失败处理。不能因为工具返回一段文字，就把它写成个体亲历或已经完成的行动。本版没有实现这种自动衔接。

## 用户执行验收

新实现尚未运行测试。仓库根目录执行：

```powershell
pwsh -File packaging/run_offline.ps1 -Suite plugins
```

源码专项只使用临时插件和人工生命包，不连接模型或平台；包含一项实际 Python 子进程，其余使用固定样本或模拟进程。日志保存在 `artifacts/offline-plugins-*.log`。它不替代打包 exe 的进程管理验收。

解压候选到新文件夹，用独立人工生命包确认：四语能打开插件页；便签示例导入后停用；确认后输入两行文字能得到便签；重开配置仍在但不会自动运行；休眠时运行入口禁用；停用、移除按说明工作。请再用人工的长耗时插件确认“停止运行”和关窗能够结束 exe 工作进程。不要在真实生命包上练习第三方代码。
