## 角色视图（原研发交付）

使用独立人工生命包，打开最新交付的 seedbank.exe：

1. 将角色放大到最大，在陪伴页按住左键上下左右拖动，确认能把脸、头顶或下半身移回可见区域，移动方向跟随鼠标。
2. 松手后不应触发打招呼；轻点仍可打招呼。滚轮能调整大小，舞台“复位”和设置“还原视图”恢复默认大小与位置。
3. 切换页面、调整窗口大小、关闭重开，确认位置与大小保留，角色不会因窗口尺寸变化跑出画面。
4. Tab 聚焦角色区域后用方向键微调，Home 复位；检查焦点可见。
5. 减少动态或已明确休眠时仍可调整构图，但不能因此恢复动画或自动活动。原休眠功能另按现有流程确认。
6. 连续拖动、缩放与播放动作，观察脸部遮罩、残影及闪烁；新功能尚无实机通过记录。

放大意味着选择局部构图；拖动可以选择展示区域，默认视图用于恢复完整构图。五页实机素材按[截图约定](screenshots.md)采集。
