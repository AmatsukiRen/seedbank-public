# 用户执行的验收步骤

测试按用户约定由用户执行。当前提交未运行网页、浏览器自动化、应用测试、验证例程或构建检查。

## 页面设计

1. 双击 `site/index.html`，确认首屏标题、头像和两个入口清楚可见。
2. 点击“相遇／记住／改变／继续”，确认文字随之切换；用 Tab、左右方向键、Home、End 检查键盘操作。
3. 点击“开始之前”，展开四个问题，确认内容可读。
4. 收窄至约 390px，再恢复桌面宽度；检查 200% 缩放时文字和按钮是否相互遮挡。
5. 关闭 JavaScript 后，四段示例应顺序显示，原生问答仍可展开；断网后本地内容应完整。

## 应用候选，源码迁入后执行

在独立人工生命包和隔离配置中检查首次启动、外观缺失时的提示、角色导入、日记日期切换、记忆来源与纠错、生活页、备份恢复和明确休眠恢复。

运行该候选对应的离线回归，保留提交与产物标识。真实模型请求需要另行明确范围和额度，不能默认沿用过去的测试预算。
