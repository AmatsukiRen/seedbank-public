# 用户执行的验收步骤

按当前约定，测试由用户执行。本次页面改版**未运行测试、验证例程、构建检查、浏览器验收或应用程序**。下面是待执行步骤，不是通过记录。

## 直接打开

双击 `site/index.html`。它不需要服务器或安装依赖；交付副本中也有相同入口。请先看角色海报、标题、故事、截图和署名是否符合你的预期。

## 三语与故事

1. 在简中、EN、日本語之间切换，检查首屏、六章故事、按钮、截图说明、问答、署名与页尾均对应所选语言。人名和原始截图中的中文保留原文。
2. 点击六个章节，确认题目、引句、正文与章末说明一起切换。
3. 用 Tab 聚焦章节，使用上下／左右方向键、Home、End 切换；确认焦点可见，Tab 可以进入正文。
4. 点击“展开全部章节”，确认六章顺序展示；切回逐章阅读后应保留此前选中的章节。
5. 打开 `index.html#chapter-4`，确认对应章节可见；进入其它语言后章节链接仍可定位。
6. 关闭 JavaScript 后重新打开，检查三语入口、全部六章、问答和图片链接仍可用。

## 版式与图片

1. 分别在桌面宽度和约 390px 宽度查看；再以 200% 缩放阅读，检查长英文、日文、章节按钮和署名是否遮挡或溢出。
2. 检查主要按钮、正文链接、当前语言和章节选中是否容易辨认。
3. 点开三张截图，确认打开的是对应原始 PNG。原图含透明度，网页浅色背景与图片查看器底色可能不同。
4. 核对画廊可见日期为 2026-11-03、程序为当天 01:50 研发版，不能理解为当前 0.0.1 画面。
5. 断网后打开，确认除手动点击的外部出处链接外，页面内容、样式、图片和章节交互都可用。
6. 开启系统减少动态效果设置；检查页面没有自动动画与轮播。检查打印预览中的六章是否完整。
7. 在 GitHub 查看三语 README 的图文、相互跳转和署名；记录深色主题对透明截图的呈现差异。
