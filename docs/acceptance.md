## 可选人工体验与复跑

1. 使用独立 Windows 测试账号解压候选 ZIP，首次打开应见创建/打开入口；不要用真实个体做验收。确认 exe 图标和窗口版本 0.0.1。
2. 未选择模型时应提示选择本地角色，无无限加载圈；创建人工个体后五页仍可使用，日记选日期可读正文。
3. 设置中选择完整的本地 `.model3.json`，放大、拖动、缩放与复位；观察静止脸部、招手后残影和连续播放，关闭重开确认偏好保留。清除选择只取消展示，不删除模型文件。
4. 检查四语页面、模型选择提示和 API Key 密码输入；Key 由测试者自有账号提供，不使用维护者凭据。真实连接需用户自己明确选择，离线脚本不会联网。
5. 回复出现时表情/招手与文字协调；历史切换、重复回执不重播。后台刷新不出现加载脸；隐藏、减少动态和明确休眠停止动态，恢复需明确操作。
6. 离线复跑可使用 `packaging/run_offline.ps1 -Suite core`、`-Suite integrations`、`-Suite security`，完整命令见 [开发说明](development.md)。当前结果见本页顶部；复跑须使用人工数据。
7. GitHub 三语首页与扩展文档的路径、浅深色阅读和署名由用户查看；新五页截图按 [截图约定](screenshots.md)采集。
8. 插件管理专项为 `packaging/run_offline.ps1 -Suite plugins`，只使用临时人工目录；当前结果见顶部。手动步骤见[插件指南](plugins.md#用户执行验收)，包括便签示例、重开、休眠和子进程停止。
9. 人工体验时，在创建页及“设置 → 对话”展开服务说明，确认云端预设、本地服务与自有 Key / 模型 ID 要求；在陪伴页“更换角色”及“设置 → 外观”确认选择入口。切换四语，调整为 860 × 640，查看换行与滚动；取消文件选择应保持原设置。自动界面回归不替代对所有服务、导出模型和显示设备的实测。
