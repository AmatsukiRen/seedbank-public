# 用户执行的验收步骤

按当前约定，测试由用户执行。本次页面改版**未运行测试、验证例程、构建检查、浏览器验收或应用程序**。下面是待执行步骤，不是通过记录。

## 直接打开

双击 `site/index.html`。它不需要服务器或安装依赖；交付副本中也有相同入口。请先看角色海报、标题、故事、截图和署名是否符合你的预期。

## 三语与故事

1. 在简中、EN、日本語之间切换，检查首屏、六章故事、按钮、截图说明、问答、署名与页尾均对应所选语言。人名和原始截图中的中文保留原文。
2. 点击六个章节，确认题目、引句、正文与章末说明一起切换。
3. 用 Tab 聚焦章节，使用上下／左右方向键、Home、End 切换；确认焦点可见，Tab 可以进入正文。
4. 点击“展开全部章节”，确认六章顺序展示；切回逐章阅读后应保留此前选中的章节。
5. 打开 `index.html#chapter-4`，确认对应章节可见；进入其它语言后章节链接仍可定位。
6. 关闭 JavaScript 后重新打开，检查三语入口、全部六章、问答和图片链接仍可用。

## 版式与图片

1. 分别在桌面宽度和约 390px 宽度查看；再以 200% 缩放阅读，检查长英文、日文、章节按钮和署名是否遮挡或溢出。
2. 检查主要按钮、正文链接、当前语言和章节选中是否容易辨认。
3. 确认旧三张陪伴页已从首页撤下，五个入口分别为陪伴、日记、记忆、生活和设置。
4. 新图处于待采集状态，不能出现“当前五页已验收”等描述。采集要求见 screenshots.md。
5. 断网后打开，确认除手动点击的外部出处链接外，页面内容、样式、图片和章节交互都可用。
6. 开启系统减少动态效果设置；检查页面没有自动动画与轮播。检查打印预览中的六章是否完整。
7. 在 GitHub 查看三语 README 的图文、相互跳转和署名；确认浅色、深色主题均能阅读。
8. 打开新私有库主分支首页，确认品牌标题图、原头像、五个图形入口与五个章节横条出现。导航应跳到本页的故事、导览、开发扩展、开始方式和署名；逐一检查三语。收窄窗口时导航可换行，字体需可读。
9. “网页源文件”在 GitHub 中应打开 HTML 源码；要看独立网页，应下载后本地打开。它不应被误认为已部署的站点。

## 出处与边界

确认人设列为 ZipZipPipe、上善无形；原画及拆分为神宫凉子；Live2D 建模为霓虹猫_NeonNeko；模型为 DeepSeek-chan（大肥鱼）。模型作者链接明确称“原始预告”，不冒充最终下载入口。

确认故事标为创作示例，仓库仍显示私有设计稿和暂无下载。没有伪造公开下载按钮、使用人数或验收通过结果。

## 应用候选另行验收

本轮在原研发交付中增加用户主动运行的五页采集入口，正常启动不会调用它；生产组装不代表验收通过。应用源码迁入后，在独立人工生命包中检查启动、模型导入、日记日期切换、记忆来源及纠错、生活页、备份恢复和明确休眠恢复；保留对应提交、安装包标识与日期。真实模型请求需另行明确范围和额度。

现有旧版记录可以作为研发历史阅读，不能替代新的候选结果。
