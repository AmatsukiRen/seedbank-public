## 当前具体待确认项

**公开自有源码与发行程序分别核对。** 支持 Live2D 不等于项目不能开源。AIRI 的[构建插件](https://github.com/proj-airi/unplugin-live2d-sdk/blob/main/src/vite/index.ts)会取得 Cubism Web SDK；它的 [Nix 文件](https://github.com/moeru-ai/airi/blob/main/nix/common.nix)则将自身 MIT 代码与非自由 Cubism 依赖区别记录，并对再分发提出疑问。本次只依据这些公开实现说明，未推断 AIRI 是否另有协议，也不把另一项目的公开状态当成 SeedBank 的授权。

SeedBank 继续保留 Live2D：自有源码与构建说明可以独立准备，Windows 包的 SDK 条件另行落实。当前 Git 中仍有头像和模型截图，其用途许可也适用于源码仓库公开，不能因不附模型本体就跳过。两类交付的内容与待办见[迁入和分发说明](repository-plan.md#源码公开与-windows-发行分别推进)。

**Live2D 是最明确的一项。** 官方定义涵盖通过添加文件加载不定数量模型的应用，也专门让 AI / chatbot 产品核对该类别。SeedBank 可以选择用户本机任意模型，因此**根据功能推断很可能属于可扩展应用**，这还不是 Live2D 对本项目作出的正式分类。该类别要求发行前审查与专门协议，适用于个人和小企业；完全免费的应用在特定条件下也可能获批，不能因此推定一定收费或自动豁免。开发插件界面并不是这一问题的唯一原因。

须向 Live2D 说明实际功能并确认分类、免费开源条件、二进制与源码发行边界和所需声明。[询问草稿](licensing-inquiry.md)已准备，**尚未发送**。仅把 SDK 拆成一个下载插件并不能自动解决其发行条件，本轮没有采用这种假设。

**模型和头像分开处理。** 本库和 Windows 候选不包含完整模型、纹理、动作或 PSD，用户自己从作者渠道取得。随包须知推荐 VTube Studio，也提到可按其他 Live2D 软件说明导入，因此不能说它只能用于 VTube Studio；但不随包模型也不能替代随包须知要求的产品推广用途确认。新增作者发布视频已通过公开元数据确认作者和署名，工房链接按维护者提供记录，见[素材来源](assets.md)。角色许可已有一手声明，不再把“找不到 CC 原帖”列为缺项；具体参考图来源和模型的独立条件仍须分别处理。

**Qt 的后续工作是具体的发行义务。** 根据 [Qt 官方 LGPL 说明](https://www.qt.io/development/open-source-lgpl-obligations)，需保留相应权利、许可与通知、提供适用的源码取得方式及替换/重新链接路径。既有应用源码、构建方法和通知不足以证明单文件包全部合规。前轮已经执行隔离程序验收，但没有进行 Qt 库替换与重新链接试验；本次不重跑，实际缺项与补充材料见 [Qt 发行材料](qt-redistribution.md)。

这份记录描述查到的事实和项目判断，不改变根目录许可，不为作者作授权承诺，也不授权发布仓库、Release 或向任何第三方发信。

## 打包依赖修正

本次静态审查发现旧候选收进了 `qtvirtualkeyboardplugin.dll` 与 `Qt6VirtualKeyboard.dll`。它们对应的 [Qt Virtual Keyboard](https://doc.qt.io/qt-6/qtvirtualkeyboard-index.html) 提供商业许可或 GPLv3，不能按一般的 LGPL 模块处理。应用没有直接使用该模块，现已在 PyInstaller 最终二进制与数据清单中明确排除；实际打包检查结果见 [验收记录](acceptance.md)。

此修正不改变其他 Qt、Live2D、角色或模板的许可义务。运行测试通过也不是素材作者授权或 SDK 发行协议；Live2D 类别与品牌用途仍需维护者取得外部确认。已有询问草稿可以使用，本轮没有代为发信或作授权承诺。

随后进一步读取同一个旧 exe 的归档和 DLL 导入记录，发现未使用的 `qmldbg_quick3dprofiler.dll` 又带入 `Qt6Quick3DUtils.dll`。后者的 [Qt 6.12 源码](https://github.com/qt/qtquick3d/blob/v6.12.0/src/utils/qssgutils_p.h)标注 GPLv3/commercial，不可按普通 LGPL 模块处理。打包源码同时排除消费者和库，保留 2D UI；2026-11-04 用户的新候选归档与隔离运行检查通过，不改变旧包仍包含它们的历史事实。

另外发现 wheel 许可证目录只有商业引用文件，已在源码中补充 Qt 上游 LGPLv3/GPLv3 正文及采集逻辑。仍须完成 Qt 内嵌第三方声明、对应源码提供和可行的修改库重建路线；没有以增加两个文本文件宣称全部合规。
