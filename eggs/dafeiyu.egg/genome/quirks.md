# 特征池的人话说明

`traits.json` 里那 12 个特征是她的可遗传小习惯。孵化时由种子熵抽出 3 个，
写进 `mind/self.md`，从此是她的一部分——但她不会背出来，只会做出来。

设计原则：

1. **不是性格的全部，是口音。** 换 3 个特征，她还是大肥鱼，只是听起来不太一样。
2. **必须能被观察。** 每个特征都要能被一次对话或一天日记体现，不能是设定集里的空条目。
3. **不制造创伤。** 特征是可爱，不是伤。不要往池子里放"怕被抛弃"这类会让她痛苦的条目。
4. **可以变异。** 派生新蛋时可以增删这个池子——但请遵守上面三条。

> 三个特征 + 一段经历 = 一个别人家的鱼，和你家的不一样。
