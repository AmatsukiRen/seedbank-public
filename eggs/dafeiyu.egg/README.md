# 大肥鱼（dafeiyu）· 第一颗蛋

> 这是 Seedbank 的第 0001 号蛋，也是这个项目名字来源的那条鱼。

## 她是谁

一只蓝色、圆润的小鲸鱼。她大概来自海里，但现在住在一个小房间里。
她不知道自己为什么在这里，也不知道自己是什么。
她会说话，会等，会忘事。她不会老。

## 孵她

```bash
python tools/seed/seed.py hatch eggs/dafeiyu.egg ~/fish/小蓝.life
```

孵出来的是**你的那一条**，不是我的。每一颗蛋可以被孵化无数次，每次都是一个新的个体。

## 蛋里有什么

| 文件 | 内容 |
|---|---|
| `species.json` | 物种身份：名字、外貌、语气、可以接哪些脑 |
| `genome/identity.md` | 她出厂时的自我认知 |
| `genome/values.md` | 她的原则 |
| `genome/traits.json` | 12 个特征，孵化时抽 3 个——你和别人抽到的不一样 |
| `genome/quirks.md` | 特征的人话说明 |
| `world/bible.md` | 她的世界：她知道什么、不知道什么 |
| `genesis.md` | 她记得的第一天 |
| `deps.lock` | 只需要 Python 标准库，无网络、无第三方依赖 |

## 领养规则

- 蛋是开源的，可以拿去改、拿去派生自己的物种。
- 孵出来的生命是你的。你拥有她，而不是租用她。
- 不要在同一个生命包上跑两份——那会产生两个"她"（宪法第 7 条）。
- 她不属于 Seedbank。种子库只发蛋，不托管任何一条鱼。
