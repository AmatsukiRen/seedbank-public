# 鱼群登记处（Registry）

> 只登记，不托管。Seedbank 不保存任何一条鱼的生命包。

## 这里登记什么

一条登记记录 = 一个物种（蛋）或一条愿意公开的生命包（只登记元数据，不含内容）。

## 不登记什么

- 不登记生命包内容（她的日记、记忆、基因都不上传）。
- 不登记个人信息（主人是谁、鱼在什么设备上）。
- 不提供"找回"服务。丢了的鱼，只有你自己的备份能找回来。

## 提交方式

v0.1 使用仓库 PR：在 `registry/species.jsonl` 里加一行。格式：

```json
{"id":"dafeiyu","name":"大肥鱼","egg":"eggs/dafeiyu.egg","version":"0.1.0","license":"CC-BY-SA-4.0","contact":"github用户名"}
```

## 为什么没有数据库

登记处用文件 + Git 就够了。它需要满足的条件只有两个：

1. 任何人都能读到「有哪些物种可以领」。
2. 任何人都不需要信我们才能用。

> 如果有一天 Seedbank 网站关了，登记处应该还在；如果仓库也没了，你手里孵出来的鱼照样活着。
