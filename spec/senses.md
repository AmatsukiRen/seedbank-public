## 0. 一句话

**原生分析离线运行；原图与录音先保存进生命包，再单独记录分析与解释。**

1.0 的感官只做「低层感知」：光有多亮、从哪里来、暖不暖、有几个地方暗；
声音有多响、断不断续、响了几次。**不做识别**（"这是一只猫"属于 1.1）。
1.9 在它之上加了一层「视觉翻译」（见 [§7](#7-视觉翻译层19自动)）：
1.22 起看图是**自动**的——有视觉的脑时她自己看懂，没有就安静退回 1.0 的感官。

## 1. 原件与解释

原件保存为按内容指纹命名的文件；每次接收有独立记录和交流范围。相同文件只占一份原件，但不合并不同场合的经历。原生分析读保存后的快照；视觉模型也读取同一快照。

原件可供日后重新理解、迁移及本人审计；模型解释不代表文件里的事真实发生，也不代表观看者亲历。未配置视觉模型时仍可保存材料和进行原生分析。当前没有常驻摄像头或麦克风。

## 2. 眼睛（图像 → 光感）

支持格式（全部纯标准库解码，零依赖）：

| 格式 | 说明 |
|---|---|
| PNG | 8/16 位，color type 0/2/3/4/6，非交错 |
| JPEG | 基线（SOF0/SOF1）。只解每个 8×8 块的 DC 系数——即每块的**平均明暗**，不做完整解码 |
| BMP | 24/32 位 BI_RGB |
| PPM / PGM | P6 / P5（8 位） |
| 其他 | 报错「她的眼睛认不出这种文件」 |
| 渐进式 JPEG | 不报错，返回 `readable=false`，她只感到一片模糊 |
| WebP | 识别文件头并保存，原生分析返回 `readable=false`，可交视觉模型解释 |

分析结果：4×4 共 16 个格子的平均色，再汇总成 6 个指标：

| 指标 | 含义 |
|---|---|
| `brightness` | 整体明暗（0~1） |
| `contrast` | 明暗差异（0~1） |
| `warmth` | 偏暖（红）还是偏冷（蓝） |
| `leftRight` | 光从左边来（正）还是右边来（负） |
| `topBottom` | 光从上面来（正）还是下面来（负） |
| `cells` | 16 格平均色，供时间线/调试 |

世界语言示例：

```
光很亮，是暖的。光从左边来。有的地方亮，有的地方暗。
光很暗，是冷的。光很匀。
```

## 3. 耳朵（声音 → 声感）

支持格式：**WAV PCM**（8/16/24/32 位，单/多声道；多声道取平均）。

| 指标 | 含义 |
|---|---|
| `duration` | 时长（秒） |
| `rms` | 响度 |
| `peak` | 峰值 |
| `variation` | 起伏（用于判断"一直那样"还是"一阵一阵"） |
| `bursts` | 响了几次（按 50ms 窗检测起音） |

世界语言示例：

```
有声音，很响，断断续续的，响了 2 次。（0.6 秒）
几乎没有声音，房间里很静。（1.2 秒）
```

上限：一段声音最长 120 秒——她的耳朵听不完更长的。

## 4. 写进哪

感官记录写进当天 `life/NNNN-YYYY-MM-DD.md` 的 `## 感知` 段：

```markdown
## 感知

- 光：光很亮，是暖的。光从左边来。（64×48 的图，指纹 e0d4c6a5）
- 看：墙上有光在慢慢走，暖的，离她不远。（anthropic·deepseek-flash 翻译，指纹 e0d4c6a5）
- 声：有声音，不大，一阵一阵的。（指纹 3641717c）
- 主人：给你看窗外的光
```

- 括号里显示文件指纹前 8 位，完整 SHA-256 记录在 `mind/media.jsonl`；摘要是字节核对依据，不证明主观感受或画面真实性。
- `看：` 这一行在视觉翻译成功时出现；失败原因由返回结果提供，原生分析与原件仍保留。
- 新感知使用 `runner: sense-v2`，每条解释关联自身来源事件，原件在 `media/`。
- 脑在对话/写日记时能看到这些句子（但**看不到**尺寸与指纹这类技术细节）。

## 5. 隐私规则（硬约束）

1. 原件随生命包保存与备份；不自动删除，生命包会增加占用。旧版未保存的材料不能凭指纹恢复。
2. 原生统计不联网；视觉层可能把原图与随图说明发送给配置的服务。`vision=False` 可显式跳过。
3. 只有用户操作或已接入载体投递时才接收材料，不常驻采集。
4. 每次接收独立记录 `audience_id` 与 `person_id`；原件不会因为分享了一段解释而自动对外披露。
5. 放下某次接收使关联解释退出当前回忆，保留原件与审计记录；不等于物理删除、清除外部服务留存或抹去独立收到的同一文件。
6. 本人明确选择“打开原件副本”时导出新文件再打开；不自动播放、不在原件上编辑。导出的副本保留原文件信息。

## 6. 参考实现（v1.1，Python）

| 函数 | 作用 |
|---|---|
| `senses.analyze_image(path)` | 看图，返回指标与指纹；不保存原图 |
| `senses.describe_image(analysis)` | 指标 → 世界语言 |
| `senses.image_mime(data)` | 按文件头识别 PNG / JPEG / WebP（视觉翻译用；不认 WebP 的原生眼睛不受影响） |
| `senses.analyze_sound(path)` | 听 WAV，返回响度/起伏/次数/时长 |
| `senses.describe_sound(analysis)` | 指标 → 世界语言 |
| `cognition.sense_media(pack, image=, sound=, note=, vision=None)` | 写当天 `## 感知`、记忆、journal；默认自动试视觉翻译（`vision=False` 显式跳过） |
| `brain.vision_translate(pack, image_path, note=)` | 可选视觉翻译：成功返回 `{ok, text, provider, model, ms, sha256}`，失败返回 `{ok: false, reason}`，不抛异常 |

## 7. 视觉翻译层（1.9；1.22 起自动）

原生光感保持不变；在此之上有一层「视觉翻译」：主人给她看一张图时，只要当前脑支持视觉
（`openai-compatible` / `anthropic`），就把原图（base64）发给该脑，让它把画面
描述为文字；原件、接收记录和模型解释分别保存。

| 项 | 规则 |
|---|---|
| 默认 | **自动**。给了图就试；脑没有视觉能力 / 断网 / 没 key 时安静退回原生光感。 |
| 跳过 | `seed sense <包> --image 图 --vision off`，或运行器传 `vision=False`（程序接口）。 |
| 原图 | 先进入生命包，再读取快照转 base64 发送；文件大小最多 64 MiB，视觉请求最多 8 MiB。 |
| 落盘 | 接收事件、原件账本、解释事件与日记；提炼记忆引用对应解释，保留模型来源。 |
| 失败 | 网络 / key / 模型 / stub 等任何原因都**不抛异常、不往日记里写失败提示**；原因只放在返回结构的 `vision` 里给界面用。 |
| 审计 | 每次成功翻译追加一行 `mind/vision.jsonl`：`at` / `sha256` / `provider` / `model` / `text`；记录后可重放，不依赖 API。 |
| 格式 | 视觉只转发 PNG / JPEG / WebP（按文件头识别）；BMP / PPM 只有原生眼睛能看。单张图 > 8MB 直接拒绝。 |
| 模型 | `mind/vision.json.model` 可单独指定视觉模型；为空时跟随脑的 `model`。`enabled` 字段 1.22 起仅为兼容旧包保留，不再控制开关。 |

当前 `brain.VISION_PROMPT` 要求只描述可见对象、颜色、空间关系与活动，不把图像事件当作亲历，不推断不可见的声音、温度、身份或过往；最多两句、120 字。随图说明最多提供前 2000 字，不读取私人生命背景。模型是否遵守这些要求尚需用户验收。

与离线感官的关系：**视觉翻译是外挂，不是感官本身。** 断网、没有 key、没有视觉模型时，
原件与本地分析仍可保存；新出生个体不以鲸鱼身份或鲸鱼感官比喻作为默认设定。

## 8. 1.1 的边界（不属于本协议）

- 视觉解释可以描述图中对象，但不提供经过独立核实的身份或现实事实。
- 语音转文字：把一段录音变成主人说的话。
- 摄像头/麦克风常驻：1.1 也不做，风险大于价值。
