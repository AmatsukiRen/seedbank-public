# 第一次启动：她怎么被领回家（1.19）

> 当前默认种子改为 `open.egg`，默认目录改为 `~/Seedbank`；词频只整理话题线索，不生成信念。以下保留旧设计记录，冲突部分以 [development.md](development.md) 为准。

一个从没碰过 Seedbank 的人，双击 `seedbank.exe` 之后应该只看到一件事：**一个能走完的向导**。
这篇写清楚向导做了什么、配置文件放在哪、以及「离线也能长大」是怎么实现的。

## 1. 第一次启动

双击 `seedbank.exe`（或 `seed window` 时还没有鱼）→ 弹出「初次见面」向导，四步：

1. **欢迎**：一句话说明她住在你的文件夹里、记忆可以带走、不需要网络。
2. **起名字**：默认「小蓝」；名字规则（≤24 字、不允许 `<>:"/\|?*` 与控制字符、不能以空格或句点结尾）
   与 `seed hatch` 完全一致，输入不合法时红字提示，不会悄悄改成别的名字。
3. **她住在哪**：默认 `<你的用户目录>/fish/<名字>.life`，可以「换个地方…」；这一页也说明
   「她的一生就是这个文件夹，搬家 = 复制文件夹」。
4. **选脑**：三种——
   - **先不接**（离线 stub，永远可用，不花钱、不需要 key）
   - **本地模型**（自动探测本机 Ollama / LM Studio / vLLM 等常见端口，可点选；也可以手填地址与模型名）
   - **云端**（DeepSeek / Claude / OpenAI 兼容等预设，填「环境变量名」而不是 key 本身）

最后点「开始孵化」→ 在后台孵化一条属于你的鱼 → 直接打开「她的房间」。

向导本身是只读展示 + 写一次配置/孵一个生命包；**任何一个步骤都可以退回上一步**，Esc 或右上角 ✕ 取消，取消不会留下半条鱼。

## 2. 配置放在哪

```text
~/.seedbank/config.json     # 向导写的配置（默认鱼的位置）
~/.seedbank/ui.json         # 窗口设置（置顶、开机自启、上次的房间、几何）
```

`config.json` 的形状：

```json
{
  "format": "seedbank/config@1",
  "version": 1,
  "default_pack": "C:\\Users\\你\\fish\\小蓝.life",
  "created_at": "2026-10-31T12:00:00Z",
  "updated_at": "2026-10-31T12:00:00Z"
}
```

`seed start` 会按 `default_pack` 打开她的房间；文件坏了或那条鱼已经不在了，就当没配置（重新走向导/`seed setup`），不会崩溃。

## 3. 本地模型接口

本机跑着的 OpenAI 兼容服务，直接用：

```bash
seed local                       # 看看本机有没有能用的模型
seed setup --name 小蓝           # 无界面创建（默认先不接脑）
seed brain 小蓝.life --set --adapter openai-compatible \
  --base-url http://127.0.0.1:11434/v1 --model qwen2.5:7b
seed brain 小蓝.life --test      # 测一下这个端点
```

探测的常见端口：

| 服务 | 地址 | 说明 |
| --- | --- | --- |
| Ollama | `http://127.0.0.1:11434/v1` | 要 `ollama serve`；模型名可留空，探测会自动列 |
| LM Studio | `http://127.0.0.1:1234/v1` | 在 LM Studio 里开 Local Server |
| vLLM / llama.cpp | `http://127.0.0.1:8000/v1` | OpenAI 兼容端点 |
| 其它 | `http://127.0.0.1:<端口>/v1` | 只要支持 `/v1/models` 与 `/v1/chat/completions` |

- **本地端点不需要 key**：`api_key_env` 可以为空；如果是需要占位 key 的服务，随便设个环境变量、填任意值也行。
- 云端服务仍然只存**环境变量名**（例如 `DEEPSEEK_API_KEY`），不存 key 本身；换电脑时把环境变量带过去就好。
- 探测只发两个请求（`/v1/models` 与一小段补全），失败就报「连不上」，不会影响她继续说话（脑失败会自动退回离线 stub）。

## 4. 离线也能长大（`seed grow`）

她的学习不发生在模型权重里，而发生在**她的文件夹里**——所以离线（甚至没有脑）也能长大一点点：

- 材料：最近几天她的记忆与日记（见闻、对话、自己写下的东西）。
- 长法：找那些**反复出现、跨了不止一天**的词（「灯塔」「海边」），把它写成一句信念：

  ```
  mind/beliefs.md  ←  - 我好像越来越在意「灯塔」。
  ```

- 同时写一条 `kind=thought`、`tags` 含「成长」的记忆，和一行 `mind/growth.jsonl` 留档。
- 一天只长大一次；已经在意过的事不重复写。
- 内置的 `seed off`（如果她那段时间睡着，窗口会顺手跑一次）与手动 `seed grow` 走同一套逻辑。

**底线**：成长只追加、不删除；它不改写历史，只是让她对「自己在意什么」多一句说法。

## 5. 一键包怎么装

见 [打包说明](packaging.md)。打包后的 exe 里带上了：

- `tools/seed/seedbank/` 全部模块与资源
- `assets/pet/`（她的动画）
- `eggs/dafeiyu.egg`（第一颗蛋，向导孵化用）

所以装到一个干净目录、没有仓库也能完成第一次启动。
