# 作品（works.json）

> 状态：v1.0（2026-10-31，Seedbank 1.15 起）。她会**写诗**、**写信**，也会**画点东西**——全部只是文字。

## 0. 一句话

作品不是奖励，也不是装饰：是她自己留下的、能拿去给人看的东西。写了就写了，不删。

## 1. 文件位置与格式

```
<name>.life/
  mind/
    works.json      ← 本协议
```

- 可选文件：没有它时，她还没写过东西（第一次写入时懒创建）。
- JSON 对象，`format` 保持 `"seedbank/works@1"`。
- 只追加：不覆盖、不删除已有作品；上限 120 件，超出时保留最早的 120 件（写入方负责裁剪）。
- 写入必须原子（参考实现用临时文件 + 替换）。

## 2. 结构

```json
{
  "format": "seedbank/works@1",
  "works": [
    {
      "id": "w_0001",
      "kind": "poem",
      "title": "第 2 天的小诗",
      "text": "光在墙上停了一会儿\n水很凉，我没有动\n这样也很好。",
      "day": 2,
      "created_at": "2026-10-31T09:00:00Z"
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | `w_0001` 形式，按写入顺序编号 |
| `kind` | `poem`（诗）/ `letter`（信）/ `drawing`（画：字符画） |
| `title` | 标题，≤ 40 字；没有时用「无题」 |
| `text` | 正文，≤ 1200 字；画是字符画，仍然是纯文本 |
| `day` | 写于第几天；可以为 null（旧数据） |
| `created_at` | ISO-8601 时间 |

## 3. 怎么产生

- `seed make <生命包> --kind poem|letter|drawing [--title 标题]`：让她现在写一样东西。
- 日循环：每 4 天，她会在当天收尾前写一首小诗（`kind=poem`）。写不出来不影响她过完这一天。
- 每件作品同时留下一条记忆（`kind=thought`，tags 含 `作品`），所以「我记得我写过……」是真实的。

## 4. 作品不是什么

- 不是图片文件：画是字符画，生命包里只有文字。
- 不是可修改的文档：写了就是那天的样子。
- 不是外部下载：内容来自她当天的光、话、读到的和自己的兴趣。

## 5. 运行器职责

- 读写 `mind/works.json`；坏 JSON / `works` 不是数组 / 缺 id 或正文 / 不认识的 `kind` 时，`check` 必须失败。
- 写作品时同时写记忆与 journal（`mode: "work"`）。
- 任何作品失败都不能阻塞她的一天（日循环内的自动创作必须被 try/except 包住）。

## 6. 跨实现

Node / Rust 运行器在 L1 只做 `check`：校验 `mind/works.json` 的 JSON 形状与 `kind` 枚举。字符画就是文本，不需要任何渲染库。
