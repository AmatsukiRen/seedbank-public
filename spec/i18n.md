# 界面语言协议（i18n）

> 版本：v1.0（2026-10-31，1.20.0）
>
> 这条协议只规定「窗怎么说话」，不规定「她怎么说话」：界面语言可以换，她的日记、记忆、感觉和提示词不翻译。

## 1. 语言包

- 位置：`tools/seed/seedbank/locales/<locale>.json`（UTF-8 无 BOM、2 空格缩进、flat JSON）
- key = 中文原文；value = 该语言的译文
- 缺 key 时回落到中文原文，永远不报错
- 支持的语言（1.20）：`zh_CN`、`en_US`、`ja_JP`、`ko_KR`

## 2. 语言选择

按顺序取第一个可用值：

1. 环境变量 `SEEDBANK_LANG`（如 `en_US`）
2. 用户配置 `~/.seedbank/config.json` 的 `language`
3. 系统语言（Windows UI 语言映射到上述四语）
4. `zh_CN`

## 3. 占位符

- 命名占位符：`t("孵化失败：{error}", error=...)`
- 序号占位符：`t("熟悉度 {0}%").format(percent)` —— `t()` 只做查表与替换命名占位符，序号占位符由调用方 `str.format` 处理
- 译文必须原样保留占位符集合（CI 检查）

## 4. 不翻译的东西

- 她的声音：感官描述（`describe_image` / `describe_sound`）、提示词、日记与记忆正文、承诺/遗憾/告别/梦的文字
- 结构标记：`## 对话`、`## 感知`、`## 见闻`、`## 今天`、`# 第 NNNN 天 · 日期`
- 数据默认值与枚举内部值：`主人`、`她`、`外界`、`载体`、`关系`、`日子`、`安静`、`无题`、`WORK_LABELS`、`PLAN_CHOICES` 等
- 生命包、蛋、协议向量：语言是载体的显示层，不进入生命包，不影响任何哈希

## 5. 加一种语言

1. 复制 `locales/zh_CN.json`（或从 `en_US.json` 出发），逐条翻译
2. 在 `i18n.py` 的 `LOCALES` / `LOCALE_LABELS` 注册
3. 跑 `python tools/seed/test_i18n.py` 与 `python -m unittest discover -s tools/seed`（会校验 key 集合与占位符）
4. 设置页会自动出现该语言选项（窗口按 `available_locales()` 渲染）

## 6. 跨实现

i18n 属于 Python 参考实现的**界面层**：Node/Rust 运行器不需要语言包，跨实现一致性协议（`spec/runtime.md`）与此无关。
